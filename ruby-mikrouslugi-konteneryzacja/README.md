# Programowanie w języku Ruby. Mikrousługi i konteneryzacja

Helion, in Polish.

Ruby is a modern, multi-paradigm language and, with Rails, one of the fastest ways to build web applications. The book goes through the Ruby language, how Rails works (with a close look at Rack), how to keep solutions at the right quality, and how to run them on VMware ESXi virtualisation and Docker containers on OpenShift Origin, OKD and Nomad. Practical examples lead to a microservice architecture, with GitLab as code repository, issue tracker, wiki and CI/CD.

- About the book: https://michalasobczak.pl/posts/programowanie-w-jezyku-ruby-mikrouslugi-i-konteneryzacja.html
