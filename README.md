# Publications

Books and e-books by Michał Sobczak, with their source code and companion materials.
Each folder is one publication. Descriptions and free PDFs are also on [michalasobczak.pl](https://michalasobczak.pl/?cat=publications).

| Folder | Publication | Publisher | Materials |
|---|---|---|---|
| [simple-hpc](simple-hpc) | **Simple High Performance Computing. Podstawy elektroniki i budowa komputera w symulatorze** — electronics from first principles to a working digital computer, built in a circuit simulator | self-published, 2021 · ISBN 978-83-8273-126-2 | TINA-TI circuits, C64 code, [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/978-83-8273-126-2_Simple-High-Performance-Computing-5-10-1.pdf) |
| [opencl](opencl) | **OpenCL. Programowanie CPU i GPU** — the OpenCL standard on old and new hardware, with GPU speed-ups up to 50× over the CPU | e-book, 2022 | Java/JOCL examples, [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/OpenCL.pdf) |
| [jakosc-oprogramowania](jakosc-oprogramowania) | **Jakość oprogramowania. Podręcznik dla profesjonalistów** — what software quality is, how to measure it and how to keep it in a real project | Helion | design patterns, tests, fault-tolerant system diagrams |
| [ruby-mikrouslugi-konteneryzacja](ruby-mikrouslugi-konteneryzacja) | **Programowanie w języku Ruby. Mikrousługi i konteneryzacja** — Ruby, Rails and Rack, quality, then deployment on VMware ESXi, Docker, OpenShift/OKD and Nomad, with GitLab CI/CD | Helion | code for every chapter |
| [ruby-on-rails-cwiczenia](ruby-on-rails-cwiczenia) | **Ruby on Rails. Ćwiczenia** — Ruby and Rails basics through exercises, ending with a time-management web app | Helion, 2006 | description only |
| [poradnik-dla-milosnikow-roslin](poradnik-dla-milosnikow-roslin) | **Poradnik dla miłośników roślin – to nie jest takie trudne** — a gardening guide grown from turning a wasteland plot into a garden | Ridero, 2019 · ISBN 978-83-8189-386-2 | [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/978-83-8189-386-2_Poradnik-dla-milosnikow-roslin-LIGHT.pdf) |

All books are in Polish.
