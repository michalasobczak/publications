# Publications

Books written or edited by Michał Sobczak, with their source code and companion materials.
Each folder is one publication. Descriptions and free PDFs are also on [michalasobczak.pl](https://michalasobczak.pl/?cat=publications).

| Folder | Publication | Publisher, date | ISBN | Materials |
|---|---|---|---|---|
| [opencl](opencl) | **OpenCL. Programowanie CPU i GPU** — the OpenCL standard on old and new hardware, with GPU speed-ups up to 50× over the CPU | Ridero, 2022 | 978-83-8273-803-2 | Java/JOCL examples, [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/OpenCL.pdf) |
| [simple-hpc](simple-hpc) | **Simple High Performance Computing. Podstawy elektroniki i budowa komputera w symulatorze** — electronics from first principles to a working digital computer, built in a circuit simulator | Ridero, 2021 | 978-83-8273-126-2 | TINA-TI circuits, C64 code, [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/978-83-8273-126-2_Simple-High-Performance-Computing-5-10-1.pdf) |
| [jakosc-oprogramowania](jakosc-oprogramowania) | **Jakość oprogramowania. Podręcznik dla profesjonalistów** — what software quality is, how to measure it and how to keep it in a real project | Helion, 21 April 2020 | 978-83-283-6102-7 (print), 978-83-283-6951-1 (e-book) | design patterns, tests, fault-tolerant system diagrams |
| [poradnik-dla-milosnikow-roslin](poradnik-dla-milosnikow-roslin) | **Poradnik dla miłośników roślin. To nie jest takie trudne** by Aleksandra Sobczak — edited and photographed by Michał Sobczak | Ridero, 2019 | 978-83-8189-386-2 | [free PDF](https://michalasobczak.pl/wp-content/uploads/2022/09/978-83-8189-386-2_Poradnik-dla-milosnikow-roslin-LIGHT.pdf) |
| [ruby-mikrouslugi-konteneryzacja](ruby-mikrouslugi-konteneryzacja) | **Programowanie w języku Ruby. Mikrousługi i konteneryzacja** — Ruby, Rails and Rack, quality, then deployment on VMware ESXi, Docker, OpenShift/OKD and Nomad, with GitLab CI/CD | Helion, 9 April 2019 | 978-83-283-5241-4 (print), 978-83-283-5886-7 (e-book) | code for every chapter |
| [ruby-on-rails-cwiczenia](ruby-on-rails-cwiczenia) | **Ruby on Rails. Ćwiczenia** — Ruby and Rails basics through exercises, ending with a time-management web app | Helion, 2006 | 83-246-0661-0 | description only |
