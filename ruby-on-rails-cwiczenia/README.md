# Ruby on Rails. Ćwiczenia

Helion, 2006, in Polish.

A practical introduction to building web applications with Ruby on Rails. Through exercises you learn the Ruby language — object-oriented design, text processing, files and directories, errors and exceptions — and the Rails environment on an application server. The last chapters build a time-management web application.

- About the book: https://michalasobczak.pl/posts/ruby-on-rails-cwiczenia.html
